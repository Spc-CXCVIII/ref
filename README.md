# Hi - Icon Greeting Interface

A simple greeting interface that displays a collection of SVG icons.

## Contents

This repository contains:
- `index.html` - A responsive web page displaying a "Hi!" greeting with animated SVG icons
- `chat-round-call-svgrepo-com.svg` - Chat/call communication icon
- `circle-location-arrow-svgrepo-com.svg` - Location/navigation arrow icon  
- `hydropower-coal-svgrepo-com.svg` - Power/energy icon

## Usage

Open `index.html` in a web browser to view the greeting interface. The page features:
- Responsive design that works on desktop and mobile
- Hover animations on the icons
- Clean, modern styling with a gradient background

## Icons

The three SVG icons represent:
1. **Communication** - Chat/call functionality
2. **Navigation** - Location and direction
3. **Energy** - Power and sustainability

Each icon is interactive with hover effects for better user engagement.
